# Security policy

Please report vulnerabilities privately through GitHub security advisories ("Report a vulnerability" under the repository's Security tab). Do not open a public issue for security problems.

Scope note: HerdR plugins are not sandboxed. herdr-find runs with your user's permissions, reads pane scrollback locally and talks to the HerdR Unix socket. See the Privacy and trust section of the README for the full list of what it reads and runs.
